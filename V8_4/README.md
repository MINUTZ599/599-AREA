# 599 AREA V8.4 - Knockback Aura

This package has two runtime sides:

- `Client.lua` — run as the client/LocalScript side.
- `Server.lua` — place in `ServerScriptService` in your own Roblox experience.

The knockback feature is server-controlled and uses the `599KnockbackRequest` RemoteEvent, so it does not depend on player-to-player physical collision.
